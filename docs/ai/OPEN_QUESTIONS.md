Этот файл — самостоятельный реестр неопределённостей для разработки. Дата последней сверки: 2026-09-14.

Нерешённый вопрос блокирует только зависимую реализацию. Продолжать работу над остальными частями задачи. Не превращать приведённые ниже предложения в окончательные правила продукта.

## Рабочие технические решения

В актуальном документе оставлены task_materials с nullable variant_id, несколько файлов через submission_media и создание child_tasks после «Взять». Уведомления первого контура предложены через результаты/бейдж; значения лимитов не зафиксированы. Фон линии, ссылки на фигуру узла, access_applications и поля сертификата — рабочая логическая модель, а не доказательство наличия реализации.

В текущем локальном файле приложение В отсутствует, хотя описания таблиц ещё ссылаются на него. По исходным ответам и сохранившемуся тексту нет окончательного решения о task_rewards, slug/icon категории и полноценной модели подписок. Не считать всю текущую схему окончательно утверждённой только по её версии v0.4.
