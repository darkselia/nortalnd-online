# Нортландия — автономный прототип

Откройте `index.html` двойным щелчком и выберите нужную версию. Можно открывать отдельные HTML-файлы напрямую. Переносите всю папку целиком, сохраняя вложенные файлы.

Установка React, Node.js, npm, сборка и локальный сервер не нужны. В папке только HTML, CSS, обычный JavaScript и изображения; внешних библиотек и сетевых загрузок нет.

- `school/login.html` — вход (вымышленный логин и любые 6 цифр).
- `school/welcome.html` — приветствие Норт-коммандера.
- `school/school.html` — мастерские, карта и бэджик.
- `desktop.html` — десктопный прототип.
- `mobile.html` — мобильный прототип.

Это перенос демонстрации: вход, данные, награды и действия не подключены к серверу. Заглушки исходника, включая видео и скачивание материалов, остаются заглушками. Установка как PWA в этой файловой версии не предусмотрена. Шрифт заменён на системный, чтобы страницы не зависели от Google Fonts.

Оформление находится в CSS рядом со страницами и в `nortlandia-theme.css`. Разметку экранов создают соответствующие `.js` через небольшие локальные DOM-утилиты `ui.js`; JSX и React отсутствуют. Исходный прототип не изменён.

Для разработчика: `node check.cjs` проверяет формирование пяти экранов и сценарии в упрощённой модели DOM: навигацию, вход, приветствие, поиск мастерской, диалог, взятие задания, реакции блога и локальные ссылки HTML. Это не визуальный браузерный тест. Встроенный браузер среды разработки запретил открытие `file://`, поэтому визуальная проверка не выполнена. Для просмотра прототипа этот проверочный скрипт и Node.js не требуются.
