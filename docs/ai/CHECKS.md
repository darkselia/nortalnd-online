# Проверки разработки

Ниже перечислены сценарии будущих прикладных проверок. Выбирать только относящиеся к изменению; таблица не означает, что эти тесты уже написаны.

В backend существуют pytest-проверки PostgreSQL, взрослого Account и общей основы API. Frontend использует Vitest; состав и границы проверок описаны в [TESTING.md](../../frontend/docs/TESTING.md). Команды качества приведены в корневом [README](../../README.md#проверки). Playwright пока не подключён.

| Область | Проверяемый результат |
| --- | --- |
| Детский вход | Код с ведущим нулём принимается как строка; невалидный код не создаёт сессию; ограничение перебора работает |
| Тип субъекта | Детская сессия не даёт взрослые полномочия и наоборот; совпадение UUID не меняет тип субъекта |
| Scope | Браузер не может читать/изменять чужое задание через список, detail или прямой action; истёкшее назначение не работает |
| Семья | Родитель видит только связанных детей; доступ к одному чату не открывает переписку другого ребёнка |
| Создание семьи в MVP | Аккаунты и семейные связи создаёт только уполномоченный сотрудник; родитель не создаёт ребёнка через скрытый endpoint |
| Заявки после MVP | Повторная обработка не создаёт дубли кабинетов |
| Знакомство | Первое открытие даёт обычный start; повторное — альтернативный при наличии; дата первого знакомства не перезаписывается |
| Публикация | Одной/двух галочек недостаточно; три галочки без обязательного видео также недостаточны; конкурентное согласование даёт один переход |
| Предпросмотр | Просмотр не создаёт child_tasks, награду и обязательство выполнения |
| Варианты | Нельзя привязать вариант или его материал к другому заданию |
| Попытки | Доработка создаёт следующую попытку; старая сохраняется; несколько файлов видны в нужной попытке |
| Проверка | Шаблонный текст, отзыв и чат не подменяют друг друга; запрещённый переход отклоняется |
| Начисление | Повтор HTTP-запроса/worker и два конкурентных принятия не удваивают ресурсы; кэш сходится с журналом |
| Файлы | Чужой media_id или URL не даёт доступ; незавершённая/чужая загрузка не привязывается к попытке |
| Истечение доступа | Сохраняются аккаунт, связи, история и ресурсы; ограничения соответствуют согласованному правилу |
| Интерфейс | Загрузка, пустые данные, ошибка, повтор запроса, истечение сессии; мобильная компоновка, клавиатура и длинный текст |

Репутационные границы, счётчик отказов, текстовые ответы диалога и повторная выдача сертификатов проверяются по решениям соответствующих Q08/Q06/Q09. Не закреплять в тестах догадки как продуктовый контракт.

## Первый сквозной сценарий MVP — план

После приёма семьи вне сайта и подтверждения оплаты уполномоченный сотрудник создаёт кабинеты и семейные связи → ребёнок входит и проходит онбординг → открывает линию → берёт опубликованное задание → отправляет несколько файлов → браузер возвращает на доработку → новая попытка принимается → награда появляется один раз → повтор принятия не меняет баланс.

Отдельно проверить отказ в доступе по чужому child_task_id и просмотр родителем чата без разрешения. Конкурентные транзакционные проверки выполнять с выбранной PostgreSQL, чтобы не приписать другой БД такое же поведение.

## Что сообщать после изменения

Назвать реализованный сценарий, затронутые файлы и результат действительно выполненных проверок. Отдельно обозначить моки, непроверенную интеграцию и зависимые открытые вопросы. Наличие runner или успешный запуск без тестовых файлов не считать прохождением продуктовых тестов.
